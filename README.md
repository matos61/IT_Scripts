**IT_Scripts** is a curated collection of automation and administration scripts I’ve developed and refined over time to support endpoint security, system compliance, cloud identity management, and general IT operations.

This repository contains scripts targeting a variety of platforms and tooling, including:
- Windows PowerShell automation (Exchange Online mailbox provisioning, Duo MFA debugging, SentinelOne health checks)
- macOS compliance and automation utilities
- Cross-platform Bash scripts for security scanning and operational tasks

## Overview

This repo centralizes practical, reusable, and enterprise-ready scripts for IT professionals, with an emphasis on:

- **Idempotent design** (safe to run repeatedly)
- **Structured output** (CSV/JSON reports + logs)
- **Self-contained tooling** (minimal external dependencies)
- **Operational readiness** (exit codes suitable for MDM/automation pipelines)

Whether you are managing cloud identities, securing endpoints, automating compliance checks, or integrating with MDM systems like Intune or Addigy, these scripts provide a strong foundation and real-world examples.
